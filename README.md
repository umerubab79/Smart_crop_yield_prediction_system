# 🌾 Smart Crop Yield Prediction System

A Full-Stack Machine Learning Web Application that predicts crop yield based on environmental and agricultural factors.

## 🚀 Features

* User Registration & Login Authentication
* Crop Yield Prediction using Machine Learning
* FastAPI Backend API
* Streamlit Frontend Interface
* SQLite Database Integration
* Prediction History Tracking
* Download Prediction Results as CSV
* Interactive Dashboard
* Country and Crop Selection from Dataset

## 🛠️ Tech Stack

### Frontend

* Streamlit

### Backend

* FastAPI
* Python

### Database

* SQLite
* SQLAlchemy ORM

### Machine Learning

* Scikit-Learn
* Pandas
* Joblib

## 📊 Input Features

* Country
* Crop Type
* Year
* Rainfall
* Pesticides Usage
* Average Temperature

## 🎯 Output

* Predicted Crop Yield (hg/ha)


### Run Backend

uvicorn backend.app.main:app --reload

### Run Frontend

streamlit run frontend/Home.py
